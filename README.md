# Бот графіка відключень для Telegram-каналу

Щохвилини бот перевіряє графік Львівобленерго на сайті poweron.loe.lviv.ua і в Telegram-каналі LOE. Коли з'являється новий графік на сьогодні чи на завтра, бот публікує в канал офіційну картинку з підписом:

```
💡 Оновлений Графік на Сьогодні (20.11.2026)
Останнє оновлення - 17:10
20.11.2026
```

## Налаштування

### 1. Бот
1. У Telegram відкрий **@BotFather** → `/newbot` → придумай назву та юзернейм (має закінчуватись на `bot`).
2. Скопіюй токен (вигляд `123456789:AA...`).
3. Канал → Адміністратори → Додати адміністратора → знайди бота → залиш право «Публікувати повідомлення».

### 2. Репозиторій на GitHub
1. github.com → **New repository** → назва `loe-bot` → **Public** (див. нижче чому) → Create.
2. На сторінці репозиторію: **uploading an existing file** → перетягни **вміст** папки `loe-bot`.
   Папка `.github` прихована у Finder: натисни `Cmd + Shift + .`, щоб її побачити, і перетягни її теж.
3. Commit changes. Перевір, що в репозиторії є файл `.github/workflows/check.yml`.

**Чому Public:** у приватному репозиторії безкоштовно лише 2000 хв Actions на місяць, а перевірка кожні 5 хв це ~8600 запусків. Кожен запуск рахується мінімум як 1 хвилина, тож ліміт закінчиться на 7-й день. Для публічних репозиторіїв хвилини безлімітні. Токен і канал зберігаються в Secrets, і їх ніхто не бачить.

### 3. Секрети
Репозиторій → **Settings → Secrets and variables → Actions → New repository secret**:

| Назва | Значення |
|---|---|
| `BOT_TOKEN` | токен від BotFather |
| `CHANNEL_ID` | `@назва_каналу` (для приватного каналу: `-100...`) |

### 4. Запуск
**Actions** → «Перевірка графіка» → **Run workflow**. Перший запуск одразу опублікує поточний графік, далі бот перевіряє сам.

## Перевірка на Маці без публікації
```bash
cd loe-bot
python3 -m venv .venv && source .venv/bin/activate
brew install tesseract tesseract-lang   # для Telegram-джерела
pip install -r requirements.txt
DRY_RUN=1 python bot.py
```
Покаже підпис і посилання на картинку, нічого не надсилаючи.

## Запуск на Маці замість GitHub
```bash
export BOT_TOKEN="токен" CHANNEL_ID="@канал" LOOP_MINUTES=5
python bot.py
```
Бот працює, поки відкритий Термінал і Мак не спить.

## Як це працює
- **Два джерела:**
  1. API сайту poweron.loe.lviv.ua (`api.loe.lviv.ua/api/menus?type=photo-grafic`): картинка + текст, сьогодні і завтра;
  2. Telegram-канал LOE [@lvivoblenergo](https://t.me/s/lvivoblenergo): картинки з графіком, дата і час «станом на» розпізнаються з картинки (Tesseract).
- **Без дублів:** кожна версія графіка = (дата графіка, час «станом на»). Для кожної дати бот пам'ятає останню опубліковану версію (`state/state.json`) і публікує лише **строго новішу**. Та сама версія з другого джерела або старіша версія пропускається. Якщо версія однакова в обох джерелах, береться картинка з сайту (вона чіткіша).
- **Telegram-пост приймається лише тоді, коли зійшлися всі перевірки:** заголовок «Графік погодинних відключень», реальна дата в плашці, повністю розпізнаний рядок «станом на», графік на той самий або наступний день, а час посту відрізняється від «станом на» не більше ніж на 90 хв. Будь-який сумнів → пост пропускається, графік прийде з сайту.
- **Розклад:** кожен запуск у GitHub Actions ~55 хв перевіряє джерела щохвилини і наприкінці сам запускає наступний. Cron кожні 15 хв лише страхує, якщо ланцюжок обірветься.
- Пам'ять бота комітиться в репозиторій одразу після кожного поста. Якщо зберегти її не вдалося, бот зупиняється і більше нічого не публікує.
- **Другий запобіжник від дублів:** перед кожним постом бот перечитує свій канал (t.me/s/...) і не публікує версію, яка там уже є, навіть якщо файл пам'яті загубився. Працює для публічного каналу.
- Підпис: «Сьогодні» чи «Завтра» визначається за датою графіка (київський час).
- Якщо одне з джерел тимчасово лежить, бот працює з іншим.
